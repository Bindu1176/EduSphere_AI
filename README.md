Let's be honest.

Being a student today means having **17 browser tabs open**.

One for notes.

One for assignments.

One for PDFs.

One for YouTube.

One for AI.

One for your resume.

One for internships.

One for that Google Drive folder you swear you'll organize someday.

And somewhere in between all of that...

**You're supposed to actually learn.** 😭


# 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Bindu1176/EduSphere.git
```

### 2️⃣ Enter the project

```bash
cd EduSphere
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Configure environment variables

```env
YOUR_API_KEY=your_key_here
```

### 5️⃣ Start EduSphere

```bash
npm run dev
```

Open the local development URL and...
